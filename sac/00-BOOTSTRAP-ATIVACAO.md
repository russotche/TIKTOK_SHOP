# RETOMADA DE EXECUÇÃO EXISTENTE

Após o despacho canônico, uma solicitação explícita de sincronização/retomada é delegada ao [00 — RUNTIME / STATE MACHINE — V2](./00-RUNTIME-STATE-MACHINE-V2.md). A modalidade é recuperada do checkpoint validado, nunca de comando alternativo de entrada.
